# 🎓 Student Performance AI

## 📌 Overview

Student Performance AI is a Machine Learning project that analyzes various factors affecting student academic performance and predicts outcomes based on historical data.

The project includes data preprocessing, visualization, and predictive analysis to identify the key factors influencing student success.

---

## 🚀 Features

* Student performance analysis
* Data visualization
* Correlation heatmap generation
* Attendance vs Exam Score analysis
* Machine Learning prediction model
* Educational insights and recommendations

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 📊 Dataset

The dataset contains various student-related factors such as:

* Attendance
* Study Hours
* Sleep Hours
* Previous Scores
* Family Support
* Internet Access
* Motivation Level
* Exam Scores

These factors are analyzed to understand their impact on academic performance.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/bhavana1234-bit/student-performance-ai.git
```

Move into the project directory:

```bash
cd student-performance-ai
```

Install required packages:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Run the analysis:

```bash
python student_performance.py
```

Run the application:

```bash
python app.py
```
